# Codex 每轮验收记录模板

- 运行 ID / 任务 ID / 轮次：
- 对应执行记录与任务单：
- 相对初始状态的实际改动：
- 范围及已有改动保护检查：

| 条件 ID | PASS / FAIL / NOT_RUN | Codex 独立检查的方法 | 实际结果与证据位置 |
|---|---|---|---|

- 本轮结论：ACCEPTED / REPAIR_REQUIRED / BLOCKED / INCOMPLETE
- 若需返修：失败条件、复现方法、证据、建议定位方向和不能退化的条件。
- 若停止：具体阻碍、已尝试的有效措施、需要的用户输入或环境变化。

- 用户目标与最终完成情况：
- 交付产物与使用方法：
- 业务概念、规则与版本来源：
- 主要改动及范围核对：

| 必要验收条件 | PASS / FAIL / NOT_RUN | 独立验收证据 |
|---|---|---|

- 执行与返修轮次、主要问题和解决结果：
- 未执行检查、未完成项及其影响：
- 实际模型（如可确认）、执行限制或其他交付限制：

仅在所有必要条件通过且无必需工作遗留时使用 ACCEPTED。把 CLI 执行成功与任务验收成功分开表述。
